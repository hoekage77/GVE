Skill System

Rendering capabilities and skill management

Overview

The Skill System is the pluggable rendering layer of the Generative Visual Engine. Each skill represents a complete rendering environment (Three.js, p5.js, D3.js, Anime.js) with defined capabilities, templates, and execution parameters.

Supported Skills

Skill Domain Version Best For
Three.js 3D 0.160.0 3D scenes, WebGL, animations, interactive 3D
p5.js 2D 1.9.0 Creative coding, generative art, 2D sketches
D3.js Data Viz 7.9.0 Charts, graphs, data visualizations, SVG
Anime.js Animation 3.2.2 DOM animations, SVG animations, timelines

Skill Loading Flow

1
Check Skill Registry
Look up skill by ID and retrieve definition, capabilities, and requirements.
2
Acquire Sandbox
Get compatible sandbox from warm pool or provision new one with matching base image.
3
Install Dependencies
Install skill-specific NPM packages (three@0.160.0, p5@1.9.0, etc.).
4
Mount Templates
Copy skill template files to sandbox for code scaffolding and helper functions.
5
Initialize Runtime
Start skill runtime server and verify health. Ready for code execution.

// OrbitControls for interaction

// Animation loop

  requestAnimationFrame(animate);
  controls.update();
  renderer.render(scene, camera);
}

Skill Scoring

// Scoring algorithm
function scoreSkill(skill, intent) {
  let score = 0;
  
  // Domain match (45%)
  if (skill.domain === intent.targetDomain) {
    score += 0.45;
  }
  
  // Capability coverage (25%)
  const requiredCaps = intent.requiredCapabilities;
  const providedCaps = skill.capabilities;
  const coverage = requiredCaps.filter(c => 
    providedCaps.includes(c)
  ).length / requiredCaps.length;
  score += coverage * 0.25;
  
  // Constraint fit (15%)
  score += checkConstraints(skill, intent.constraints) * 0.15;
  
  // Reliability (10%)
  score += skill.reliability.successRate * 0.10;
  
  // Warm pool (5%)
  if (skill.warmPoolAvailable) {
    score += 0.05;
  }
  
  return score;
}

Code Execution in Sandboxes

User code is executed in a Node.js vm context with skill-specific shims and mock environments.

Execution Context

// VM context setup (runner-script.js)
const context = {
  // Console
  console: { log, error, warn },
  
  // Timers
  setTimeout, clearTimeout,
  setInterval, clearInterval,
  
  // Animation frame mock
  requestAnimationFrame: (cb) => setTimeout(cb, 16),
  
  // Skill globals
  THREE: createThreeJSShim(),
  p5: createP5Shim(),
  d3: createD3Shim(),
  anime: createAnimeShim(),
  
  // Scene tracking
  __sceneObjects: [],
  __animations: [],
  __renderCount: 0,
  __frameCount: 0
};

// Execute with timeout
vm.createContext(context);
const script = new vm.Script(code, { timeout: maxMs });
script.runInContext(context);
